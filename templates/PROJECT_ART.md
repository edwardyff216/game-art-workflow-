# 项目美术说明模板

按项目选填，可使用 **不适用** 或 **待确定**。确认数值时记录依据和验收条件。

| 字段 | 填写内容 |
| --- | --- |
| 项目信息 | 名称、根目录、版本、引擎与渲染器、维护者 |
| 美术方向 | 形状语言、比例、配色角色、材质类别、细节密度、边缘和表面处理 |
| 参考来源 | 文件路径或链接、版本、日期、视频时间码、作者或生成方式、使用限制 |
| 参考分析 | 分列直接观察、尺寸估算与补充设计，标明遮挡、结构矛盾和待确认事项 |
| 资产类型与使用场景 | 资产家族、场景角色、使用距离、交互方式、优先做的代表资产或小场景 |
| 尺度与约定 | 单位、模块网格、源和引擎的正面及上方向、固定件与活动件的原点、尺寸依据 |
| 镜头与观察 | 代表机位、投影、视场角或正交范围、位置、裁剪范围、输出分辨率、近中远验收范围与移动范围 |
| 平台与性能 | 目标平台、验收设备、帧时、材质槽、三角形数、贴图内存、同屏实例及 LOD 目标与测量方法 |
| 材质与导出 | 材质模型、纹理密度及精度、颜色和数据色彩空间、通道、法线方向、透明、烘焙、格式、轴向与依赖 |
| 模块、碰撞和交互 | 连接接口和容差、连续内壁与遮挡、碰撞代理、接触或通行测试要求 |
| 光照与渲染 | 诊断与最终照明、反射来源、曝光、色调映射、允许的后处理及同机位对照方式 |
| 文件组织与命名 | 参考、源文件、脚本、贴图、导出、引擎场景、预览、验收记录与命名规则 |
| 版本与复现 | 源、脚本参数、贴图、导出、引擎实例的对应关系，工具版本、运行入口和回退方式 |
| 通用流程 | 引用本库的 `WORKFLOW.md` 或固定版本 |
